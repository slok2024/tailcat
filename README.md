# Tailcat 项目介绍

**tailcat** 是由 Tailscale 官方开源的一个命令行工具（CLI）和 Go 语言库。

简单来说，它是**“带有 Tailscale 网络穿透和 WireGuard 加密能力的新一代 netcat (nc)”**。它允许你在两台（或多台）跨越不同网络的设备之间快速建立安全连接，而**完全不需要注册 Tailscale 账号，也不需要将设备加入同一个 Tailnet**。

---

## 💡 核心特点与优势

1. **零账号、零控制平面 (No Control Plane / No SSO)**
   - 普通 Tailscale 需要登录账号、分配虚拟 IP、由 Central 控制平面管理设备节点。
   - `tailcat` 完全脱离了 Tailscale 的控制平面（服务器管理端）。没有账号、密码、用户权限或设备的概念。

2. **复用 Tailscale 强悍的数据平面 (Data Plane)**
   - 底层继续使用 Tailscale 开源的核心数据层技术：**WireGuard 端到端加密**、**magicsock NAT 穿透/打洞**，以及打洞失败时的 **DERP 中继**。

3. **基于“地址令牌”建立连接**
   - 服务端运行 `tailcat` 监听时，会生成一串包含公钥和握手信息的地址（如 `tc...` 开头的字符串）。
   - 客户端只要拿到这个地址，就能直接发起建立连接。将这个地址当作临时密码使用即可。

4. **纯用户态运行 (Userspace Only)**
   - 运行它**不需要 Root/管理员权限**，不需要创建 TUN 虚拟网卡，也不需要修改系统的路由表或 DNS 设置。

5. **轻量管道 (Pipe & Proxy)**
   - 像经典 `netcat` 一样，默认可以直接重定向 `stdin` 和 `stdout` 来传输文本或文件。
   - 支持通过 SOCKS 代理模式透明转发其他工具（如 `curl`、`ssh`）的流量。

---

## 🛠️ 工作流程

1. **启动监听 (Listen)**
   - 在目标机器上运行 `tailcat` 命令。它会自动生成一对密钥（支持一次性临时密钥，也支持持久化密钥），并输出一串专属连接地址（Tailcat Address）。
2. **共享地址 (Share)**
   - 将生成的地址安全地发给需要连接的人、机器或 AI Agent（例如通过 IM 软件、剪贴板等）。
3. **发起连接 (Connect)**
   - 客户端输入该地址发起连接。双方会先通过 DERP 服务器握手，随后自动尝试 NAT 打洞建立点对点直连；若打洞失败，则自动回退走 DERP 中继加密传输。

---

## 🎯 适用场景 vs 传统 Tailscale

`tailcat` 专为**即时、短期、无状态**的连接需求设计：

- **给 AI Agent 提供临时的沙箱/机器访问权**：许多自动化脚本或 AI Agent 需要访问某台 VM 执行任务，但它们无法完成复杂的 SSO 登录流程，且不需要持久的网络拓扑身份。
- **点对点临时文件传输 / SSH**：比使用网盘或 ngrok 更简单，命令敲完即用，发完即关。
- **CI/CD 流水线调试**：给 GitHub Actions 或 GitLab Runner 中的临时测试容器快速暴露调试端口。
- **临时暴露服务/演示**：想给朋友展示一下本地运行的 Web 服务，无需将对方加入自己的 Tailnet。

### 对比一览

| 特性 | **Tailscale** | **tailcat** |
| :--- | :--- | :--- |
| **部署定位** | 长期、可治理的企业级/个人虚拟局域网 | 短期、即用即弃的点对点隧道 |
| **账号/登录** | 需要（SSO / 邮箱等） | **不需要** |
| **设备 IP** | 分配固定 Tailscale IP（如 `100.x.y.z`） | **无 IP** |
| **网络权限控制** | 支持 ACL、身份鉴权、日志审计 | **无内置控制面**，持“地址”即有权访问 |
| **权限要求** | 需要系统 Admin / Root（部署 TUN 设备） | **普通用户权限即可** |

---

## ⚠️ 注意事项与局限性

1. **连接令牌即密钥**：由于没有账号鉴权，`tailcat` 生成的连接地址（Address）相当于明文密码。**切勿公开发布到 GitHub 或社交媒体**。
2. **中继限速/延迟**：在无法 P2P 直连的情况下，流量需要走 DERP 中继节点。Tailscale 官方提供的公共 DERP 可能会有速率限制或网络延迟问题。
